# 项目结构索引

This index points to the current structure-maintenance notes.

- `docs/project_structure_refactor_plan.md`: scaffold-only refactor plan and
  migration guardrails.
- `docs/indexes/project_artifact_index.md`: human-readable index of current
  report, test artifact, dry-run, manual review, and future scaffold roles.
- `docs/indexes/project_tool_index.md`: human-readable index of current
  root-level CLI entrypoints, outputs, advisory status, and RAG/Qdrant/LLM
  boundaries.
- `docs/indexes/project_test_index.md`: human-readable index of current test
  suites, test reports, fixtures, and dry-run artifacts.
- `docs/indexes/project_maintenance_index.md`: maintenance entrypoint that
  links structure, artifact, tool, test, terminology, and closeout reports.
- `docs/maintenance_terms_guide.md`: terminology guide for maintenance notes.
- `reports/README.md`: future report grouping contract.
- `tools/_shared/README.md`: future shared helper contract.

Status: scaffold only. Existing `tools/*.py`, `tests/*.json`, and
version-specific docs remain authoritative until a later compatibility migration
explicitly changes defaults.
